⛓ BLOCK FORGE

LOLBeans Level Editor — programmatic / variable expression builder
ブロックをドラッグして右の枠に置いてね
はじめての方へ 👋
  1. 左のパレットから、青い「数値・定数」ブロックを下の点線の枠にドラッグ＆ドロップしてみましょう。
  2. ブロックの中の数字はクリックすると書き換えられます。
  3. もっと複雑な式にしたいときは、オレンジの「計算」ブロックなどを枠にドロップすると、その中にさらにブロックを入れられます（入れ子）。
  4. 右側に、今組み立てた式がLOLBeansにそのままコピペできる形で表示されます。

出力コード

Programmatic 全体式

—
使い方
左のブロックを右の枠（スロット）にドラッグ＆ドロップして式を組み立てます。
数値・変数名はブロック内をクリックして直接編集できます。

VARIABLES: LOLBeansの「EDIT VARIABLES」パネル用。各行が1つの変数（名前＝式）。上の行の変数名は下の行から参照できます。
PROGRAMMATIC: Programmatic オブジェクトの position/rotation 式。複数行を ; でつなぎ、最後の行が戻り値になります。time / startPositionX/Y/Z / startRotationX/Y/Z / duration が使えます。
